E-E – Éducation Enfant — Projet Android
==========================================
Projet Android Studio prêt à être ouvert et compilé.

1. Ouvrir ce dossier dans Android Studio.
2. Laisser Gradle synchroniser.
3. Tester sur un téléphone ou émulateur.
4. Pour Google Play : Build > Generate Signed Bundle / APK > Android App Bundle.
5. Créer une clé de signature et conserver le fichier de clé en lieu sûr.
6. Le fichier AAB signé est celui à envoyer dans Google Play Console.

Identité proposée :
Nom : E-E – Éducation Enfant
Package : com.ee.educationenfant
Version : 1.0 (code 1)
Cible Android : API 35
